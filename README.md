# Simple Interest Calculator

## Description

The Simple Interest Calculator is a simple project that calculates the interest earned or payable on a principal amount for a given rate of interest and time period.

## Formula

Simple Interest (SI) is calculated using the formula:

**SI = (P × R × T) / 100**

Where:

* **P** = Principal amount
* **R** = Rate of interest per year
* **T** = Time period in years

## Example

If:

* Principal = 10,000
* Rate = 5%
* Time = 2 years

Then:

**SI = (10,000 × 5 × 2) / 100 = 1,000**

Therefore, the **Simple Interest is 1,000**.

## Features

* Easy to understand
* Calculates simple interest quickly
* Uses the standard simple-interest formula
* Suitable for basic financial calculations

## Purpose

This project demonstrates the basic concept of simple interest and provides a simple way to calculate it using given principal, rate, and time values.
